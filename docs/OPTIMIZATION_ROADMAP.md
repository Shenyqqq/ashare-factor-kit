# 优化路线图：信息天花板假说 vs 可执行改进

> **状态**：评估文档（2026-07-30）。不打断进行中的 `stock_value_em` / 新 Barra IC / ridge 实验（agent `c9a0bb83`）；下文凡依赖新口径处标注「待 em+新 barra IC 完成后对照」。  
> **产品定位**（本仓库）：A 股多因子量化选股框架，**辅助人工选股，不做全自动交易**。模型输出得分排名，人工二次筛选后手动操作。

## 1. 背景与假说

### 1.1 观察到的事实（用户侧）

| 现象 | 含义（待数据验证） |
|------|-------------------|
| PIT / 退市 / ST 对齐后收益下降 | 此前部分收益来自幸存者偏差与 look-ahead；「真」alpha 更薄 |
| raw ≈ 老 Barra 纯化 | 在旧风格定义下，中性化未显著抬高截面可预测性 |
| 跨模型、跨因子池 Q5 高度相似 | 排序信息高度重叠 → 瓶颈更像**信息集合**而非模型族 |
| 2026 失效 | 近期 regime / 拥挤 / 微观结构变化；全样本 Sharpe 被早期时段抬高 |
| 全样本 Sharpe 有欺骗性 | 与 DSR≈0.025（`research/pbo.py`）一致：超参/实验选择偏差大 |

### 1.2 「信息天花板假说」

> 在**日频量价 + 季报财务 + 现有 Alpha 包**这一信息集合上，全市场周频截面 ML 的样本外可预测性已接近上限；再换模型 / 微调超参 / 换固定白名单，Q5 与 Top100 不会系统性拉开。

**总判（见文末）：更像待检验假说，不是定论。** 假说被证伪的充分条件是：在**因果正确、成本扣净、近年分段仍成立**的前提下，换信息集合或换目标层后，滚动 OOS IC / Top100 超额相对当前 baseline 出现**稳定、可复现**的提升。

假说**不能**否定的方向：持仓/产品层（换手、敞口、人工 overlay）、分池训练、事件/预期单独层、微观降频因子（若有数据）、二段筛选（若一段已有可测增量）。

### Q1. Sharpe≈0.5 vs 实盘门槛 1.0；不含 2026 是否接近 1.0；Top100 还能不能当选股参考？

**结论**：不能用「全样本 Sharpe≥1」一刀切判定「有没有用」。在本项目「辅助人工选股」定位下，Top100 的参考价值应用**滚动样本外 IC + 近年分段 + Top100 命中/超额**三维判断；若近 2–3 年滚动 IC 仍显著、Top100 相对全市场仍有正超额且单调性未崩，则**可作为人工初筛名单**，即使策略 Sharpe 只有 ~0.5。若仅靠 2018–2021 抬高、2023–2026 失效，则降级为「弱参考 / 仅作行业或主题提示」。

**理由**：

1. **Sharpe 门槛与产品定位**  
   - 全自动交易 / 对冲基金产品常把净值 Sharpe≈1 当硬门槛。  
   - 本仓库定位是**辅助人工**：交付物是得分排序与候选池，不是无人值守 NAV。人工可叠加：基本面复核、仓位裁量、避开主题踩踏、事件确认。此时更关键的是「名单是否仍比随机/市值加权更好」，而非单独把 Q5 多空 Sharpe 推到 1.0。  
   - 策略层 Sharpe（Top50/100 等权扣成本）仍应报告，但应标为**策略产品指标**，与「选股参考价值」分开说。

2. **如何判断「参考价值」（可执行指标）**  
   | 指标 | 过关启发式（可调） | 解读 |
   |------|-------------------|------|
   | 滚动 52 周 OOS Rank IC（周频） | 均值 >0 且 ICIR>|0.3|，近 2 年不塌 | 排序仍有截面信息 |
   | 分年 / 分 regime IC | 2024–2026 不全为负 | 排除「只吃旧样本」 |
   | Top100 vs 等权宇宙超额（扣成本） | 近 2 年年化超额 >0，胜率 ≥50% | 名单有经济意义 |
   | Top100 ∩ 次季赢家命中率 | 相对随机提升可测 | 人工「挑对」概率 |
   | 不含 2026 的子样本 Sharpe | 仅作敏感性，不作上线依据 | 防「删坏年份」作弊 |

3. **「不含 2026 接近 1.0」**  
   - 若成立，说明失效集中在近期，应优先查：风格切换、因子拥挤、微观结构监管、流动性。  
   - **不可**据此宣称系统已达标；应把 2026 当作必测 OOS 窗，或做 walk-forward 末段 holdout。

**优先级**：P0（先建立评价面板，再决定是否加大信息投入）。  
**天花板假说否定？** **否**。假说谈的是「同一信息集合下再拧模型收益有限」；不否定「当前名单对人工仍有条件参考价值」，也不否定「评价口径本身需要纠偏」。

### Q2. 二段训练（一级 top20% 池上再筛因子 + 训二段出 top100）有没有希望？

**结论**：**有希望，但是条件实验，不是默认银弹。** 若天花板假说在全市场成立，二段**不一定卵用**——若一段得分已榨干日频信息，二段在 top20% 内往往只剩噪声与风格残差。若一段在「头部 vs 尾部」强、在「头部内部」弱，二段才有空间。必须用**最小成本可证伪实验**决定，而不是先上复杂架构。

**理由**：

- 全市场截面模型擅长区分好/坏的「粗排序」；头部内部区分常需要**更短半衰期、更局部、或事件/微观**信息。  
- 二段缩小宇宙 → 有效样本量下降、IC 方差上升、过拟合风险上升（与当前 DSR 警示一致）。  
- 与「分市值池」（Q6）正交：二段是**得分条件池**；分市值是**先验分层**。

**最小成本可证伪实验（建议 2–4 GPU/CPU 日内完成）**：

1. **冻结一段**：现有周频 ridge/ensemble + `--feature-neutralize`（待新 Barra/em IC 白名单）。  
2. **伪二段（无重训）**：每期取一段得分 top20% → 在池内用**另一组特征**（如：已有大单/换手/波动/sparse event，或随机噪声对照）做截面 z-score 加权打分 → 取 top100。  
3. **真二段（轻量）**：仅在 top20% 池上用 **ridge** 重训（特征≤15，同一 holdout），禁止先看测试再调。  
4. **证伪标准**（相对一段直接 Top100）：  
   - 近 2 年 Top100 扣成本超额 **无提升** 或 IC 不显著 → 二段搁置（假说在「头部内」成立）。  
   - 稳定提升且噪声对照无提升 → 值得加特征（微观/一致预期）进二段。

**优先级**：P1（评价面板之后；真二段前先做伪二段）。  
**天花板假说否定？** **条件否定**。若假说对全市场成立，二段仍可能因「换特征集」而有效；若假说对**头部内同一信息集**也成立，则同特征二段基本卵用——实验正是为区分这两种。

### Q3. 微观数据对截面选股帮助多大？对 5 日收益是否偏弱？

**结论**：国际 LOB/OFI 文献的有效预测视界多为**高频到「数个价格变动」**，对**裸 5 日持有、直接灌日频截面**偏弱。A 股金工实践的主流路径是：**逐笔/分钟 → 日频统计量 → 周/月频选股因子**；降频后对截面仍有证据，IC 量级约数个点（RankIC 常见 0.03–0.08 量级，视因子与中性化而定），且与传统量价低相关。对「二段+微观」：**优先于全市场直接堆 LOB**，更适合作为二段/短半衰期特征或独立因子层。

**文献要点（必须查证摘要）**：

| 来源 | 用法 | 持有期 / 视界 | 效果证据 | 链接 |
|------|------|---------------|----------|------|
| Kolm et al. (2023) *Math. Finance* | LOB → 平稳 order flow (OF/OFI) → DL 预测收益 | 有效视界约 **2 个平均价格变动**；多 horizon HF | OF 输入显著优于 raw LOB；信息丰富股票（updates/price-change 高）更可预测 | [DOI](https://doi.org/10.1111/mafi.12413) / [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3900141) |
| Kolm & Westray | 多层 + 截面 OFI | 价格冲击 / 短视界 | 深档 OFI 抬 OOS R²；截面 OFI 小幅但显著增益 | [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4568641) |
| 华泰金工：逐笔成交深度学习选股 | 资金流 + 事件特征 → Transformer；输出**未来约 10 日**超额 | **周频调仓**选股 | 融合因子周频 RankIC ~10%；多头年化超额约 +2pp vs baseline；强依赖微观结构稳态 | [慧博摘要](https://wap.hibor.com.cn/repinfodetail_4284135.html) |
| 东吴「订单簿的温度」 | 成交笔数切割改进反转 | 日→月频因子 | 强化反转；多空 IR 可很高（历史区间） | [BigQuant 转载](https://bigquant.com/wiki/doc/4Um8LjwmYA) |
| 订单簿 Spread → 低频 alpha | Tick Spread → **月频**选股 | 月频 | 中性化后多空年化 ~14.6%，ICIR~−2.1；与反转/换手低相关 | [新浪研报页](http://vip.stock.finance.sina.com.cn/q/go.php/vReport_Show/kind/search/rptid/4699007/index.phtml) |
| 中信建投：多层 OFI / 订单斜率 | 高频 OFI → **月频**因子 | 高频正、降频后需变换（如绝对值） | 月频截面仍有选股力；提醒高频逻辑≠低频符号 | [迈博](https://www.microbell.com/docdetail_3265307.html) |
| 开源证券：大小单资金流 | 大单正、小单负；残差化后更强 | 日频聚合截面 | 大单强度 IC~0.025→残差~0.054 | [BigQuant](https://bigquant.com/wiki/doc/INuDH2j2ep) |

**对 5 日（周频）的含义**：

- **原始 LOB 状态 / 秒级 OFI**：证据集中在 HF；直接预测 5 日收益期望弱、成本与工程重。  
- **降频微观因子**（主动买卖失衡、大单强度、盘口 spread 日统计、逐笔事件）：A 股研报明确用于**周/月选股**，与 h5 并不矛盾；半衰期常在 **10–20 交易日**，周频合理、纯 1–2 日更吃换手。  
- 本仓库已有 `大单净流入_*`（东财，历史较短）与 sparse 事件包；**缺的是真 Level-2/逐笔管线**，不是「微观无用」。

**对「二段+微观」优先级**：P1–P2。全市场一段先用尽日频+特色；微观降频因子优先进 **IC 单因子检验 → special/二段**，不要一上来全市场 DL+LOB。

**天花板假说否定？** **否（且是证伪假说的主攻之一）**。微观降频 = **换信息集合**。

### Q4. A 股特色数据紧要吗？（大单、机构、ETF、活跃券、分析师一致预期）

**结论**：**紧要，且优先级高于再扫一圈同质化量价因子。** 事件/预期类**直接丢进高维截面 ML 易被淹没**（稀疏、覆盖偏大盘、与市值/动量共线）；更好用法是：**独立 IC 层 / special-factors 注入 / 条件仓位 / 二段特征**，而不是与 50 个 z-score 量价列平等竞争。

**分项**：

| 数据 | 仓库现状 | 建议用法 | 优先级 |
|------|----------|----------|--------|
| 大单净流入 | `factor_moneyflow_large` + `download_moneyflow`；历史短 | 残差化（对涨跌/换手）后进 IC；短窗 5–20d | P1 |
| 机构净买入/持仓变化 | `factor_institution_change` + 季报 PIT | 低频；适合月频或事件确认，周频 ML 权重宜低 | P2 |
| ETF 成交 / 活跃证券 | 未成体系 | 拥挤与主题扩散代理；适合 regime/过滤 | P2 |
| 分析师一致预期 / 修正 | **未接入** | 文献支持截面溢价；应用 **revision / surprise**，非静态 PE | P1 |

**一致预期文献要点**：

- 中国：分析师**盈利增长预测与收益正相关**（与美国长端增长预测负向不同）；乐观增长预测组合年化异常收益可观（论文报告可达约 20% 量级，需独立复现）。[ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S0927538X23002639) / [IDEAS](https://ideas.repec.org/a/eee/pacfin/v82y2023ics0927538x23002639.html)  
- 盈余预测修正、投资评级修正：日历组合月均三因子超额约 **1.34% / 0.92%**（历史样本）。[金融研究摘要](http://www.jryj.org.cn/CN/abstract/abstract143.shtml)  
- 含义：优先做 **revision / 预期差** 因子 + PIT（报告发布日），覆盖率与延迟必须审计。

**为何易被淹没**：稀疏列方差小（仓库已对 sparse 做方差对齐）；树模型可学到但 ridge 易压掉；全市场标签噪声大时，稀事件梯度被淹没。  
**更好形态**：`--special-factors event/sparse` 已有范式；一致预期应走同类 **skip neutralize + 可选方差对齐**，或二段 top20% 内使用。

**天花板假说否定？** **否**。特色数据 = 信息增量；假说若成立，更应转向这里而非继续调 lgbm。

### Q5. 周频下人工占比 vs 把 A 股特色纳入量化？

**结论**：**两者不是对立，应「量化扩信息 + 人工守制度/叙事」。** 周频换手与信息衰减快，全自动要求更高；在辅助定位下，建议量化侧把可结构化的 A 股特色（大单残差、业绩预告、分析师修正）纳入得分，人工侧保留：主题拥挤、政策、财报质量、停复牌与流动性一票否决。

**建议分工**：

| 层 | 量化 | 人工 |
|----|------|------|
| 初筛 | Top100–200 名单 + 行业中性提示 | 砍掉明显叙事陷阱 |
| 信息 | 日频因子 + 特色/事件 special | 调研、纪要、一致预期细节 |
| 仓位 | `--position-regime` 总敞口 | 大盘研判、单票上限 |
| 执行 | 回测成本假设 | 真实冲击与时机 |

**优先级**：P0（产品叙事与评价对齐）+ P1（特色入库）。  
**天花板假说否定？** **否**。假说限制的是「同质信息自动交易的 Sharpe」；不限制「人工+增量信息」的组合效用。

### Q6. 分市值池 / 指数成分内训练回测意义大不大？

**结论**：**意义大，且成本低于微观。** 全市场混合训练会让模型偏向小盘高换手结构；指数内（沪深300/中证500/1000）或市值三分位训练，可回答「alpha 是否只存在于小盘」以及「对人工常用股票池是否仍有用」。这是**诊断 + 产品对齐**，不是调参。

**理由**：

- 用户真实选股池往往接近宽基/中证500+；全市场 Top100 含大量不可投小票时，参考价值虚高。  
- 分池可改变因子 IC 符号与最优持有期（流动性溢价、反转强度）。  
- 实现路径：universe mask（成分列表 PIT）→ 同套 WF；对比滚动 IC 与 Top50 超额。

**优先级**：P1。  
**天花板假说否定？** **否**。分池是**样本与标签分布**改变；若仅小盘有 IC，假说在「可投宇宙」上被局部证伪或证实。

### Q7. 继续滚动定池并跑一次？新 Barra/em 语境下是否仍值得？

**结论**：**值得，但排在「新 IC 白名单冻结」之后，且一次对照实验即可，不要并行多 schedule 刷屏。** 滚动定池解决的是**因子集时变**，不直接打破信息天花板；若固定池与 rolling-pool 的 Q5/Top100 仍高度同形，则强化天花板假说（在现有因子库内）。

**顺序建议**：

1. 等待 `stock_value_em` + 新 Barra 定义下落盘完成。  
2. 清旧 neut / barra pure ckpt（见 AGENTS 注意事项 13）→ `ic_analysis_v2 --barra` h5/h20。  
3. `python -m research.rolling_pool --horizon 5`（及 h20 + 新 ckpt）。  
4. 单次：`run.py ... --rolling-pool-schedule ...` ridge 或 ensemble，与**同参固定 YAML**对照。  
5. 若增量有限 → 降级 backlog；把精力给特色/分池/二段。

**优先级**：P1（新 IC 后立刻做一次）；重复刷 schedule = P3。  
**天花板假说否定？** **弱相关**。Rolling-pool 是同一信息库的时变子集；假说预测「对照无显著差异」。

## 3. 对「天花板假说」的总判

| 判断 | 说明 |
|------|------|
| **性质** | **待检验假说**，不是已证伪的物理定律，也不是停研借口 |
