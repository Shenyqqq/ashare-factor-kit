## 0. 标签说明

| 标签 | 含义 |
|------|------|
| `免费可获` | AKShare / 已有落盘 / 量价自算即可 |
| `收费·高重要性` | Tushare VIP 等；对辅助选股、破量价同质化价值高 |
| `收费·中重要性` | 有增量，但非当下瓶颈或可用免费近似 |
| `收费·低重要性` | 有也不急（打板全套、分钟 RT、金股等） |
| `已有注册但数据债` | registry 已有，raw 不足或极薄 → 因子名在、信号不可用 |
| `有数据未注册` | 磁盘已有字段/表，缺因子实现 → **马上可做** |
| `已覆盖或近似覆盖` | 基础日线/财务/市值等主链已有等价或近似源 |

类型：**截面选股** / **择时或状态** / **事件稀疏**。

## 1. THS 资金流澄清（常见误解）

同花顺（THS）经 AKShare 拿到的资金流，**个股 / 行业 / 概念 / big_deal 在「缺长历史」上本质同类**：

| 种类 | 实际形态 | 长样本？ |
|------|----------|----------|
| **个股** | 「即时 + 近 N 日排行」**截面**；`moneyflow_ths_individual_*hist` 只是**每日下载归档** | 无单票多年日频历史 |
| **行业 / 概念** | 同样是多窗**截面排行** | **并不比个股更有长历史** |
| **大单 big_deal** | 成交明细快照（笔数级），不是日频资金流面板 | 几乎无长历史 |

此前缺口表写「行业/概念有数据未注册」，指的是磁盘上有**当日/多窗快照可玩**，**不是**「行业有可用长样本、个股没有」。

**为何单独弃用个股净流入因子**：用户明确判定 THS 个股净流入不可用并要求删除——已从 registry 移除（`THS_资金净流入强度_*`）。行业/大单**从未**作为已注册生产因子强推，仅在缺口表标过「有快照」。下载脚本 `data/download_moneyflow_ths.py` **保留**（归档/探索用），勿与「生产因子可用」混淆。

真正缺的日频主力流仍是：**东财大单/超大单面板**（注册已有、raw 未就绪）或 Tushare **个股资金流向（DC）** 等付费长历史。

## 2. Tushare 清单 → 仓库覆盖速览

用户提供的 Tushare 大类按「是否已覆盖」消化如下（不必逐接口抄录；门槛随积分档变化，以官网为准）。

| Tushare 大类（用户清单） | 仓库现状 |
|--------------------------|----------|
| 股票列表 / 交易日历 / ST / 曾用名 / 基本信息 | **已覆盖或近似覆盖**（AKShare `stock_list` + ST 时序；沪/北 ST 偏保守） |
| 历史日线 / 复权 / 复权因子 / 停复牌 / 涨跌停价 | **已覆盖或近似覆盖**（hfq + raw + masks） |
| 每日指标（市值/换手/PE/PB 等） | **近似覆盖**：东财 `stock_value_em` → `total_mv`/`circ_mv`/`pe_ttm`/`pb`/`turnover_rate`；Tushare `daily_basic` 可作更稳备份 |
| 每日股本（盘前） | **部分**：`share_change` + 自算/东财股本；盘前专用接口未接 |
| 财务三表 / 财务指标 / 披露日期 / 业绩预告·快报 | **近似覆盖**：`financial_indicators` + PIT；`yjyg`/`yjbb` 已接事件因子；三表明细科目仍浅 |
| 分红送股 / 审计意见 / 主营构成 | **未充分纳入** |
| 参考：质押 / 解禁 / 回购 / 大宗 / 股东人数 / 增减持 / 十大股东 | 解禁·回购·大宗·户数·增减持 **已有 raw+注册**；**质押、十大股东名册**缺 |
| 特色：盈利预测 / 筹码 / 机构调研 / 金股 / 集合竞价 / 技术因子专业版 | **大多未纳入**；研报/评级为免费伪一致预期 |
| 两融明细 / 标的 | **明细已有**（`margin_detail`）；标的名单时序未做 |
| 资金流向（个股/板块 THS·DC、大盘、沪深港通） | 东财大单 **数据债**；THS 见 §1；DC/港股通流 **未接** |
| 打板专题（涨停榜、连板天梯、游资、热榜、概念成分行情） | 量价派生涨跌停因子已有；**专题库未接**（多高积分） |
| 分钟 / 实时 RT / 港美股等 | **低优先级**（个人辅助选股非主战场） |

## 4. 优先行动（三条）

### 4.1 免费马上做

1. **仍欠的数据债（优先于新因子名）**：全市场东财 `download_moneyflow`（`moneyflow_large` 仍缺失；限流重、单票历史常仅近数月 → 可先搁置或改买 Tushare DC）。机构持仓与评级长表**已回补**，不必再当「极薄」债。研报可对未覆盖股票 `download_research_report` resume（按股跳过已有 code）。对应因子多已在 registry。  
2. **有数据未注册（薄加工）**：日频 `PE_TTM`/`PB`（与季报价值因子重复，刻意不注册）；ST 戴帽摘帽事件（用户剔 ST）。两融偿还/融券主动量/融资÷流通市值、龙虎榜 `reason`、解禁类型、股本 `change_reason`、研报 EPS 斜率/分歧、大宗卖方质量等**已注册**（两融四只走稠密轨）。  
3. **勿把 THS 截面快照当长历史资金流**；行业/概念/big_deal 仅探索。

### 4.2 值得为 Tushare 付钱的高优先级

1. **个股资金流向（DC）长历史**——在东财全市场 moneyflow 长期拉不稳时，是「大单/残差流」的正道备份（`收费·高重要性`）。  
2. **每日筹码分布 / 筹码胜率**——免费层几乎没有干净面板；小盘/破同质化高杠杆（`收费·高重要性`，约高积分档）。  
3. **正式盈利预测/一致预期修订**——中大盘与全市场辅助选股；纯小盘池可降级（`收费·高重要性`～中）。  
4. **打板专题（涨停榜、连板天梯、游资明细）**——仅当「涨停/妖股」作为认真卫星策略时上；否则用现有 limit + 龙虎榜免费线即可。  
5. **每日指标 `daily_basic` 级干净市值/换手**——若东财链路不稳时的备份（很多环境已用东财近似覆盖）。

### 4.3 可忽略（现阶段）

- THS 个股/行业净流入生产因子、技术面因子专业版、神奇九转、券商金股、转融通停更接口、港美股/期货分钟、新闻/公告单独包年（除非做 NLP 产品线）、实时 RT 包月。  
- 在未喂满免费数据债前，**不要**为「质量升级版」的解禁/龙虎榜/两融（3000 档）单独付费——AKShare 已有可用近似。
